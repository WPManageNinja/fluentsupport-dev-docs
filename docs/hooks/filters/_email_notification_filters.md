<div class="fs-docs-content">
This filter hook allows you to retrieve mailbox header data and modify it.

**Parameters**

- '$headers' (array) Mailbox header data
- '$data' (array) CC email list and hook type data

**Usage**

```php
add_filter('fluent_support/mail_to_customer_header', function ($headers, $data) {
    // ...do something
    return $headers;
}, 10, 2);
```

**Reference**

`apply_filters('fluent_support/mail_to_customer_header', $headers, [
                'cc_email'  => $ticket->getSettingsValue('cc_email', []),
                'hook_type' => 'ticket_created_email_to_customer'
            ])
`

`fluent-support/app/Hooks/Handlers/EmailNotificationHandler.php`

<explain-block title="fluent_support_ticket_email_subject">
<hr>
<div class="fs-docs-content">
This filter hook allows you to modify the subject line of any outgoing email notification sent by Fluent Support. It fires for every email type, giving you a single point to customise subjects across all notification events.

**Parameters**

- `$subject` (string) The email subject line as generated by the template
- `$ticket` (object) The ticket object the notification relates to
- `$emailType` (string) The notification event key, e.g. `'ticket_created_email_to_customer'`, `'ticket_replied_by_agent_email_to_customer'`, `'ticket_closed_by_agent_email_to_customer'`

**Usage**

```php
add_filter('fluent_support/ticket_email_subject', function ($subject, $ticket, $emailType) {
    if ($emailType === 'ticket_created_email_to_customer') {
        return '[Support] ' . $subject;
    }
    return $subject;
}, 10, 3);
```

**Reference**

`apply_filters('fluent_support/ticket_email_subject', $subject, $ticket, $emailType)`

This filter is located in <br>
`fluent-support/app/Hooks/Handlers/EmailNotificationHandler.php`
</div>
</explain-block>

This filter hook allows you to modify the body of the email sent to customers during portal signup verification or two-factor authentication. Use it to customise the message wording, add branding, or translate content.

- `$message` (string) The email body content
- `$code` (string) The verification or 2FA code included in the email

<explain-block title="fluent_support_ticket_link_portal_options">
<hr>
<div class="fs-docs-content">
This filter hook allows you to add, remove, or reorder the Customer Portal destination options shown in Global Settings. Each option controls where ticket links inside email notifications redirect customers.

**Parameters**

- `$options` (array) Array of portal destination option arrays. Each item has two keys:
  - `id` (string) — internal identifier used to store the selection (e.g., `'default'`, `'woocommerce'`, `'fluent_community'`)
  - `label` (string) — display label shown in the settings UI

**Built-in options (conditionally included):**

| id | Label | Condition |
|----|-------|-----------|
| `default` | Default Portal Page | Always available |
| `fluent_cart` | FluentCart Account Navigation | FluentCart active |
| `woocommerce` | WooCommerce Account Navigation | WooCommerce active + Pro |
| `fluent_community` | FluentCommunity Portal | FluentCommunity active |

**Usage**

```php
add_filter('fluent_support/ticket_link_portal_options', function ($options) {
    // add a custom portal destination
    $options[] = [
        'id'    => 'my_custom_portal',
        'label' => 'My Custom Portal',
    ];
    return $options;
}, 10, 1);
```

**Reference**

`apply_filters('fluent_support/ticket_link_portal_options', $options)`

This filter is located in <br>
`fluent-support/app/Services/EmailNotification/Settings.php`
</div>
